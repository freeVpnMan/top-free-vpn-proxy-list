A bot collects public `vless://`, `vmess://`, `trojan://`, `ss://`, and MTProto links and writes them here. It is not a VPN company and not a client app. You still pick an app, paste a row, and connect.

GitHub stays useful as a searchable table with latency columns. Telegram is faster because nodes die in hours. If a row fails, skip it. Do not use these servers for banking or work mail.

## FAQ

### Are the configs free?

Yes. This README and the Telegram channel do not charge. Nodes themselves belong to whoever ran the server.

### Where is the live list?

[@OnlineVpnConfigs](https://t.me/OnlineVpnConfigs). This file lags by up to a day.

### Is this a VPN app?

No. Install a client from [Awesome VPN Clients](https://github.com/freeVpnMan/awesome-vpn-clients). Ignore people selling an "official" paid plan under this name.

### Which protocols?

VMess, VLESS (including Reality), Trojan, Shadowsocks, and some Telegram MTProto links.

### A row does not connect

Normal for public lists. Take another row or open Telegram.

### Can I copy this into my own list?

Yes. [Unlicense](https://unlicense.org/). Tell people the nodes are public and untrusted.
