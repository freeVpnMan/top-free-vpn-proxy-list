### Which protocols are supported?

### A config doesn't work, why?

### Is it safe to use these proxies?

These are third-party servers operated by unknown parties, so treat them like any free VPN: do **not** log into sensitive accounts, do **not** send unencrypted traffic, and prefer TLS-enabled configs (VLESS+TLS / Trojan / Reality). Use them for bypassing censorship, not for handling sensitive data.
