### How often is the list updated?

### Which protocols are supported?

V2Ray (VMess), VLESS (including Reality), Trojan, Shadowsocks (SS), and MTProto. Any standard URI starting with `vmess://`, `vless://`, `trojan://`, `ss://`, or a Telegram MTProto link is supported by mainstream clients.

### A config doesn't work, why?

Free proxies have short, unpredictable lifespans. A node that works one minute may be saturated or blocked the next. Just try another row from the table or grab a fresher one from [@top_free_vpn_list](https://t.me/top_free_vpn_list). The list rotates constantly.

### Is it safe to use these proxies?

These are third-party servers operated by unknown parties, so treat them like any free VPN: do **not** log into sensitive accounts, do **not** send unencrypted traffic, and prefer TLS-enabled configs (VLESS+TLS / Trojan / Reality). Use them for bypassing censorship, not for handling sensitive data.
