### Are these VPN / proxy configs really free?

Yes. They are collected from publicly-posted Telegram channels and shared here at no cost, with no signup and no ads. The contents of this README are released into the public domain under [The Unlicense](https://unlicense.org/).

### How often is the list updated?

This `README.md` is rewritten **every 24 hours** with the 30 most recent configs. To get a config immediately, join [@OnlineVpnConfigs](https://t.me/OnlineVpnConfigs) on Telegram. New configs are pushed there within seconds of being collected.

### Which protocols are supported?

V2Ray (VMess), VLESS (including Reality), Trojan, Shadowsocks (SS), and MTProto. Any standard URI starting with `vmess://`, `vless://`, `trojan://`, `ss://`, or a Telegram MTProto link is supported by mainstream clients.

### A config doesn't work, why?

Free proxies have short, unpredictable lifespans. A node that works one minute may be saturated or blocked the next. Just try another row from the table or grab a fresher one from [@OnlineVpnConfigs](https://t.me/OnlineVpnConfigs). The list rotates constantly.

### Is it safe to use these proxies?

These are third-party servers operated by unknown parties, so treat them like any free VPN: do **not** log into sensitive accounts, do **not** send unencrypted traffic, and prefer TLS-enabled configs (VLESS+TLS / Trojan / Reality). Use them for bypassing censorship, not for handling sensitive data.
